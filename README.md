# ArchAI | RevitMCP AI Design Assistant

## About
ArchAI is an **LLM-powered AI design assistant** built for Revit and Dynamo.
It connects large language model API, runs on RevitMCP architecture,
enables designers to **control Revit by natural language** for architectural modeling and BIM automation.

## Core Features
- ✨ Natural language → Revit design operation, no need to write complex code
- 🔗 Based on RevitMCP communication protocol, stable and reliable
- 🧩 Seamlessly integrated with Dynamo & Revit, plug and play
- 🏗️ Oriented to architectural and nuclear power BIM design scenarios

## Installation
1. Download the latest release package of this project
2. Unzip it to your Dynamo custom packages directory:
   `%appdata%\Dynamo\Dynamo Revit\2.x\packages`
3. Restart Revit and Dynamo, you can find ArchAI nodes in the library
